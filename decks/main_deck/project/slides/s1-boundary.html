01 — 行业定义与研究框架

图 1-2

本报告把五类产品计入行业；模型厂商自营的编程产品计入，模型 API 本身不计入——这是机构口径分歧的根源

资料来源：研究整理（概念示意图）

证据 强　·　8 / 47

事实：2026 年的工具可按执行环境、仓库工作方式与用户预设分为五类架构。机制：几乎所有开发工具都已嵌入模型，"是否使用 AI"或"用谁的模型"已无法区分产品，只能按默认工作流归类。判断：模型厂商自营产品计入行业，但模型 API 本身不计入，各机构是否把 API 与服务收入算进来，就是第二章规模相差两个数量级的根源。传统开发工具是配套环节；低代码平台与直接用聊天模型是替代品，Wix 收购 Base44 说明二者正在融合。
