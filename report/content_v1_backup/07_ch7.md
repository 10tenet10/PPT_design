# 第七章 竞争格局与商业模式

本章解释行业竞争围绕什么展开，以及企业如何获得收入并维持优势。产品功能表不能替代竞争分析，因此本章先建立格局与竞争因素，再讨论商业模式与行业经济性，最后判断哪些能力容易被复制、哪些优势可能持续。涉及份额、收入与客户数的指标均注明口径；公开数据不足之处不制造排名。

## 7.1 全球及中国市场的主要竞争者

图 7-1 以"架构类型 × 目标用户"为坐标描绘 2026 年 10 月的竞争格局。按可核实的使用率口径（Stack Overflow 2026，n=12,255，多选），第一梯队为 Claude Code 65.5%、GitHub Copilot 58.7%、OpenAI Codex 29.5%、Cursor 25.5%；第二梯队包括 Google Antigravity 16.0%、Gemini Code Assist 14.6%、OpenCode 13.6%、JetBrains AI 12.8%；Windsurf 6.5%、Devin 2.9%、Replit Agent 2.3%、Trae 1.3% 等居长尾[16]。该口径的局限是：样本为专业开发者，一体化平台的用户主体不在其中；按收入口径，Lovable（年化 5–6 亿美元）与 Replit（估计 5 亿美元级）在各自细分内是领导者[36][38]。中国市场按 IDC 2025 年收入口径，阿里 Qoder 47.6% 居首，智谱、商汤、腾讯、百度随后[8]；按使用口径，Trae 自报月活 160 万[63]。企业采购口径下（Menlo，美国 495 位决策者）编程 LLM 支出中 Anthropic 占 54%、OpenAI 21%[5]。

## 7.2 不同产品类型之间的竞争与替代关系

竞争与替代同时发生在三个层面。**类型内竞争**（如 Cursor vs Devin Desktop，Lovable vs Bolt vs Base44）围绕模型接入、验证能力与价格展开。**类型间替代**：终端/CLI 智能体正在替代 IDE 内嵌助手的"主工作流"地位——Stack Overflow 2026 中 66% 的 AI 用户使用编程智能体、63% 使用聊天机器人，Claude Code 的使用率已超过 Copilot[16][17]；而 Copilot 则通过多模型、cloud agent 与 AI credits 向智能体转型[66][87]。**跨行业替代**：直接用 ChatGPT/Claude 聊天仍是最常用的 AI 编程方式之一（JetBrains 2025 中 ChatGPT 41%）[18]；低代码平台与一体化平台互相渗透（Wix 收购 Base44）[58]；外包与自由职业者是另一替代——SaaStr 事件后 Replit CEO 引述的"100 英镑 vs 10 万英镑代理报价"正是这一替代关系的宣传口径[183]。

## 7.3 波特五力分析

图 7-3 汇总五力分析。**供应商（模型）议价能力：强。** 证据包括 Windsurf 被断供、OpenAI 对 Cursor 断供、Cursor 2025 年中约 130% 的收入付给 Anthropic、优先服务层使月账单翻倍、模型厂商同时是直接竞争者、自研模型需 SpaceX 算力[44][45][52][28]。弱化因素是开源与低价模型的可得性：DeepSeek V4.1 Flash 输出每百万 token 0.60（谷时）至 1.20（峰时）美元，Kimi、Qwen 在 Bedrock 上 1.2–3 美元，Copilot 提供六家以上模型，OpenCode 接入 75 家以上提供商[80][81][66][93]。**买方议价能力与迁移成本：中等偏低。** 迁移成本低的证据：Lovable 全计划可导出 GitHub、bolt.diy 开源、Claude Code 可经三家云计费、AGENTS.md 与 MCP 标准化[83][76][68][95]；迁移成本高的证据：Lovable 不能导入已有仓库、工具特定的规则/hook/技能配置、"模型 + 优化后 harness"的配对难以在别处复制、Cursor 75% 收入来自企业席位合约[83][46][30]。**替代品威胁：中高**（见 7.2）。**新进入者威胁：两极。** 技术门槛低（开源智能体、模型 API、Base44 六人团队被收购）[93][58]，但资本门槛高（负毛利期需数十亿美元融资）、算力与接入权受制于巨头[28][36][41][49]。**现有竞争者：强而集中。** 前四名使用率均超 25%，三大模型厂商直接下场，中国厂商 2026 年由免费转向收费并提价[16][61][73]。

## 7.4 竞争因素：模型能力、工程集成、生态、分发与迁移成本

**模型能力**的差异正在收窄（第三章），但"谁能第一时间、以足够容量接入最强模型"仍是胜负手——这解释了为何 Cursor 要与四家模型厂商签多年协议[48]，以及 OpenAI 断供为何被 IDC 视为重大事件[46]。**工程集成（harness）**是应用层可建立的最实质优势：执行环境、验证闭环、上下文管理与计费系统；Cursor 在无自有前沿模型的情况下达到 40 亿美元年化收入，Claude Code 在模型厂商内部也是独立于 API 的增长引擎，都说明 harness 本身有价值。**生态**的作用在 2026 年显现：Cursor 的团队市场与 Projects、Codex 的 Plugins、Claude Code 的插件与技能、MCP 服务器注册表（9,652 条记录）[96]，使工具成为分发平台。**分发渠道**决定了谁能触达企业与非技术用户：GitHub 的仓库入口（1/3 的 PR 涉及智能体）[26]、云厂商账单通道、Google AI 订阅捆绑 Antigravity 与 Jules、SpaceXAI 把 Cursor 与 Grok 订阅合并销售[67][71]。**用户迁移成本**总体较低，这使竞争更接近"持续的能力与价格竞赛"而非"锁定后收割"，对用户有利，对应用层毛利不利。

## 7.5 商业模式：订阅、用量计费、企业服务与平台服务

## 7.6 推理、算力、研发、分发及运营成本

第四章已说明应用层的成本结构。这里补充三点对竞争有直接影响的经济事实。第一，**每任务 token 消耗在上升**：SaaStr 引述的"跑步机"分析认为每任务 token 消耗自 2023 年底起上升 10–100 倍，单价下降但每任务总成本上升；Claude Code 文档把 agent teams 的消耗标为约 7 倍[52][68]。第二，**订阅业务对模型厂商也是低毛利业务**：SemiAnalysis 估计 Anthropic 的 API 业务毛利 80% 以上而消费者订阅约 50%[54]；Anthropic 封禁第三方 harness 使用订阅登录正是为了阻止"以订阅价补贴 API 等价负载"[56]。第三，**容量是硬约束**：GitHub 2026 年 4 月暂停新注册 58 天、Anthropic 2026 年 3 月曾加工作日高峰限流，都表明推理容量而非获客是定价的首要考量[49][56]。

## 7.7 行业经济性和商业模式可持续性

可持续性取决于应用层能否在"模型成本"与"用户支付意愿"之间找到正毛利区间。公开证据指向三条路径：（1）**企业席位**——Cursor 企业定价毛利显著更好、75% 收入来自企业[55][30]；（2）**自研或蒸馏模型**——Base44 毛利目标从近零升至 60%，Cursor 被预测 2027 年毛利从 74% 升至 85%（估计值）[38][52]；（3）**平台托管**——Replit 托管毛利 80% 以上[38]。纯粹依赖前沿模型 API 转售的应用层在 2025 年被证明不可持续，这是 2026 年行业整合的经济根源。另一方面，需求侧的价格弹性较低（Anthropic 估计 −0.29；Menlo 称前沿编程用户"相当价格不敏感"）[23][5]，为透传定价提供了空间——但这一结论主要来自企业与专业用户，低基础用户表现出的 credit 焦虑（第五章）说明价格弹性在该群体可能显著更高。

## 7.8 产品差异如何影响用户选择、留存和付费

专业开发者以输出质量选择与切换工具（25.1% 因质量切换，仅 6.4% 因成本）[16]，因此模型接入与验证能力直接决定留存。低基础用户的选择受三个因素驱动：免费层与 credit 的可感知消耗、"能否不写代码做出能用的东西"、以及遇到卡点时是否有出路。Lovable 的净收入留存超过 100%（2025 年 11 月）[38]与 Trustpilot 17% 的一星评论并存[139]，说明该群体呈现"扩张型留存与高流失并存"——成功者加购 credit，失败者在"最后 10%"流失。

哪些优势容易被复制？规则文件、记忆、检查点、浏览器自测等功能在 2025–2026 年被各家在数月内相互跟进（第六章表 6-1），属于易复制能力；模型接入权、算力、企业合约与分发渠道属于难复制能力；而"在既有项目上让非技术用户可靠验收"这一能力，目前没有任何产品完备（第六章 6.7），既是空白也是潜在的差异化来源。
