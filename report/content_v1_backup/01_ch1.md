# 第一章 行业定义与研究框架

## 1.1 AI 编程工具的定义与发展背景

本报告将 **AI 编程工具**定义为：以大语言模型为核心能力，直接参与软件的编写、修改、调试、测试、部署与维护过程，并以开发者或业务构建者为直接用户的软件产品与服务。该定义有三个要件：第一，模型不只是回答关于代码的问题，而是直接作用于代码仓库或运行环境；第二，产品的交付物是可运行的软件变更，而非一般文本；第三，用户在产品中承担验收与决策角色，产品对用户的编程能力不作预设。

这一定义的发展背景可概括为三次能力跃迁。2021–2022 年，GitHub Copilot 把代码补全从基于统计的片段建议升级为基于生成模型的行级与函数级生成，工具仍完全依附于人类的编辑流[178]。2023–2024 年，聊天式交互与 AI 原生 IDE（Cursor 2023 年发布）使模型能够理解多文件上下文并执行跨文件修改，同时第一批"自主智能体"（Cognition 的 Devin，2024 年 3 月发布）尝试接管完整任务。2025 年至今，终端智能体（Claude Code 2025 年 2 月预览、Codex）、云端异步智能体和面向非专业用户的自然语言应用平台（Bolt.new 2024 年 10 月、Lovable 2024 年 11 月）把执行环境、测试与部署纳入工具的工具集；2025 年 2 月 Andrej Karpathy 提出的"vibe coding"一词在当年 11 月被 Collins 词典评为年度词，标志着"不审查代码、仅凭自然语言驱动开发"从边缘实践成为公共议题[178]。

## 1.2 主要产品形态与分类方法

产品形态的分类不宜以"是否使用 AI"或"模型来自谁"为依据，因为 2026 年几乎所有开发工具都嵌入了模型，且多数工具支持多家模型。本报告采用**三个相互独立的维度**：执行环境（本地 IDE/终端、云端容器、平台内运行时）、代码仓库工作方式（用户自有 Git 仓库 vs 平台内项目）、以及目标用户的编程能力预设（专业开发者 vs 不预设）。由此得到五类架构（表 1-1）。分类规则是"以产品的默认工作流归类"：一个产品可以跨类（如 Cursor 既是 AI 原生 IDE，也提供云端代理；Claude Code 既有终端形态，也有云会话），正文在比较时以其主要形态为准，并在第六章逐产品说明。

## 1.3 与基础模型、传统开发工具及低代码平台的关系

**基础模型**是本行业最关键的上游投入，但本报告不把模型 API 收入计入"AI 编程工具市场"。原因有二：一是重复计算——Cursor、Copilot 等产品的收入中相当部分以 API 成本形式转付给模型厂商[52]，若同时统计应用层 ARR 与模型层收入会重复；二是归属困难——同一模型 API 同时服务编程与非编程用途。但模型厂商自营的编程产品（Claude Code、Codex、Gemini Code Assist）属于本行业，因为它们的交付物和用户都符合定义。

**传统开发工具**（IDE、版本控制、CI/CD、测试框架、可观测性）是 AI 编程工具的运行基础而非竞争对手：2026 年的智能体正是通过调用 Git、测试命令、浏览器和日志来工作。它们在本报告中作为产业链的配套环节处理。

**低代码/无代码平台**与一体化自然语言应用平台存在真实的替代关系：二者都面向非专业用户、都承诺"不写代码即可交付应用"。区别在于交付物——低代码平台交付的是平台内的可视化配置，而 Lovable、Replit 等交付的是真实源代码（通常可导出到 GitHub）。Wix 在 2025 年 6 月收购 Base44 说明两类平台正在融合[58]。本报告将自然语言应用平台计入行业范围，将传统低代码平台视为替代品。

## 1.4 全球市场与中国市场的研究范围

本报告采用全球视角，以海外前沿产品为主要分析对象，同时覆盖中国市场。中国市场的特殊性在于：产品以免费策略为主、付费转化数据普遍未公开、市场规模口径差异极大（IDC 与信通院口径相差约 12 倍，见第二章）、且缺少可追溯的公开失败复盘。因此中国市场的分析以厂商公开数据与可核实的媒体报道为限，涉及份额与规模时并列标注不同口径。

## 1.5 研究方法、资料类型与主要限制

本报告以公开资料研究为基础，综合行业研究报告、大样本开发者调查、学术论文与研究机构报告、官方技术文档与版本记录、公开财务披露、以及可追溯的案例，并运用 PEST、产业链、波特五力等分析框架。证据处理遵循六条规则：（1）重要数据注明来源、时间、地域与口径；（2）区分实际值、估计值、预测值与研究推断；（3）区分官方产品声明与独立效果证据；（4）不把专业开发者调查直接推广到低编程基础用户；（5）不混用使用率、依赖率、付费率与活跃率；（6）不将不同口径的市场规模相加。
