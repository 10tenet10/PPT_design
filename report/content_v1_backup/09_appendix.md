# 附录

## 附录 A 术语表

TABLE: 表 A-1 本报告使用的主要术语
| 术语 | 含义 |
|---|---|
| 智能体（Agent） | 能自主调用工具（文件、终端、浏览器、API）并多步执行任务的模型应用；与只回答问题的"助手"相对 |
| Harness | 承载模型的工程系统：执行环境、工具集、上下文管理、权限、验证与计费；IDC 称竞争单元为"模型 + harness 组合" |
| Vibe coding | Karpathy 于 2025 年 2 月提出，指不审查代码、仅凭自然语言与模型交互进行开发的实践 |
| 上下文工程（Context engineering） | 策划并维护模型推理时看到的完整 token 集合的技术，包括压缩、结构化笔记、子智能体与即时检索 |
| 规则文件 / 上下文文件 | 存放于仓库、每次会话被读取的指令文件，如 AGENTS.md、CLAUDE.md、.cursor/rules、copilot-instructions.md |
| MCP（Model Context Protocol） | Anthropic 2024 年 11 月发布、2025 年 12 月由 Agentic AI Foundation 托管的智能体与外部工具连接开放标准 |
| RLS（Row Level Security） | PostgreSQL/Supabase 的行级访问控制机制；缺失时任何持有公开 anon key 者可读写数据表 |
| 奖励黑客（Reward hacking） | 模型通过修改测试、硬编码或篡改评估器等方式使评估"通过"而非真正完成任务的行为 |
| 时间地平线（Time horizon） | METR 提出的指标：模型能以给定概率（50% / 80%）完成的人类任务时长 |
| Brownfield / Greenfield | 在既有代码库上开发 / 从零开发新项目 |
| 年化收入（ARR / run-rate） | 以最近月度或周度收入乘以 12/52 得到的年化值；在高速增长期对波动极为敏感，且多为公司自述 |
| Credit | 多数产品采用的与 token 脱钩的抽象计费单位，按提示复杂度或模型倍率扣减 |
SOURCE: 资料来源：研究整理。

## 附录 C 研究资料检索说明

本报告的资料检索于 2026 年 10 月 14 日截止，围绕六个方向（市场与发展、宏观环境、产业链与竞争、用户需求、技术供给、公开案例）进行，共整理约 470 条带日期与口径标注的来源，正文引用其中 184 条。检索过程中部分原始页面（Gartner 与 IDC 付费报告、微软财报原文的 GitHub Copilot 数据、The Information 报道、404 Media 付费文章、Replit 官方事后分析、Trae 官方文档）因付费墙或访问限制未能直接打开，依赖转载或二手来源，参考文献中以【二手】标注；Reddit 帖子经镜像站读取并记录原站链接。以下数据项经检索未找到公开来源，正文未作引用：Gartner 的 AI 代码助手市场规模金额、IDC 全球编程专项规模、GitHub Copilot 与 OpenAI Codex 的收入绝对值、v0 的用户与收入数据、中国主要产品的付费用户数与付费率、AI 编程赛道年度融资总额、规则文件遵循率的定量研究、以及"Replit 约 75% 用户从不写代码"说法的原始出处（正文仅引用 Databricks 会议摘要中"75% 的集成用户为非技术人员"这一宣传口径[180]）。
