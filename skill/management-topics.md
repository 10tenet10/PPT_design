# 补充文档：管理学题材（先覆盖方向 2、4）

## 替换条款

**R1 研究对象**。主 skill 说的「行业」在本文里改读「对象」：方向 2 的对象是「一家企业 × 一个目标市场」，方向 4 是「一家公司 + 同业对照组（≥3 家）」。主 skill 所有「关于行业的结论」改读「关于对象的结论」，其余不变。

**R2 证据标签集**。七类，替换主 skill 的五类；标签锁定（不另造标签）与强（多类独立证据一致）/ 中 / 弱三级照旧：

| 标签 | 含义 | 附加要求 |
|---|---|---|
| 实际值 | 已发生、可在原文核对的数 | 同主 skill；调查与论文的数归此类并写 n |
| 自采数据 | 作者自己做的问卷、访谈、实地观察 | 必须写 n 与采样方式；没有 n 不得用此标签，降为「推断」 |
| 估计 | 机构或他人对现状的估算 | 同主 skill |
| 预测 | 机构或他人对未来的预测 | 同主 skill |
| 模型输出 | 作者或机构用模型算出的数：预算、预测、风险评分、情景 | 页面上列出全部输入，每个输入标前六类之一；该页强度不高于最弱输入 |
| 厂商自述 | 企业、管理层、产品页的表述 | 方向 4 里管理层讨论（MD&A）、业绩说明会的判断归此类；三表数字归「实际值」 |
| 推断 | 作者由其他证据推出的数 | 同主 skill；兜底区间照 §2 写算法 |

**R3 建议**。放开主 skill「不做 STP/4P 与创业建议」，改为：
- 建议只出现在**建议页**（发现页的变体，见「页型复用」）与讲稿；内容页标题仍是结论，不是建议。
- 每条建议 = 一句建议 + 「依据：发现 N、M」 + 强度 + **翻转条件**（出现什么证据时这条建议作废）。
- 没有发现页编号支撑的建议不写；禁止模板句（「加强品牌建设」「优化成本结构」这类没有对象和数字的句子）。
- 建议页放风险页之后；每页 ≤4 条，超过拆页。
- 仍不做 STP/4P 的套路填空，方向 7 的创业建议仍不在本文范围。

**R4 章节骨架**（替换主 skill 默认 8 章；仍是 8 章，每章开头的 `KEYPOINTS` 三行不变）：
- 方向 2：① 企业与出海边界（企业现状、出海动机、目标市场定义）② 目标市场规模与增长 ③ 目标市场 PEST（关税、准入、本地化合规单列）④ 本地产业链与供给 ⑤ 用户与渠道 ⑥ 竞争格局（本地与外来玩家、五力）⑦ 进入模式对比（出口、代理、合资、独资、并购、跨境电商）⑧ 风险与建议。
- 方向 4：① 公司与业务边界 ② 收入与增长拆解 ③ 盈利与成本结构 ④ 现金流与资产负债 ⑤ 同业对比 ⑥ 预算与预测（模型输出）⑦ 风险预警 ⑧ 发现与建议。

**R5 取证完成标准**（替换主 skill §2 的来源类清单；「每章至少两类」「一手优先」「时效」「3 路并行」照旧）：
- 方向 2 的来源类：企业财报或公开披露；目标国官方统计与监管原文（海关、统计局、行业主管部门）；国际组织贸易数据（UN Comtrade、WTO、World Bank）；第三方份额跟踪；大样本调查（n）；本地竞争者公开资料。第 ③、⑦ 章必须有监管或关税原文编号。
- 方向 4 的来源类：公司年报 / 季报三表（必须）；同业 ≥3 家财报；交易所公告与审计意见；行业第三方数据；管理层表述只能标「厂商自述」。第 ②–④ 章必须引用三表原文页码。
- 「模型输出」的每个输入都要能追溯到已编号的来源。
- 原文打不开时的降级规则照主 skill §1。

**R6 密度底线补充**。主 skill「每个内容页至少一个带来源编号的数字」对两种页例外：模型输出页的「数字」指它列出的输入；建议页可以没有新数字，但每条必须引用发现编号。

**R7 标题**。标题是关于对象的结论（「X 公司毛利率三年降 Y 个百分点，降幅集中在 Z 业务」）；建议页标题是一句总判断，不是「建议」二字。

**R8 定性对比矩阵例外**。主 skill「表格里有数字的行少于 4 行就改成关键数字页或图页」对**定性对比矩阵**（方向 2 第 ⑦ 章进入模式 × 维度，方向 4 第 ⑤ 章同业定性对照）不适用，条件：每格 ≤12 字、≤6 行 × ≤5 列、每行至少一格有来源编号、矩阵结论写进标题。超出任一条件仍按主 skill 处理。

## 页型复用

主 skill 的页型全部沿用：分隔页（E1）、关键数字页（E5）、图页（E4）、发现页、E3 结论页、表格页、方法页、风险页。只新增一个变体：

- **建议页** = 发现页的版式，每行改为「编号 → 一句建议 / 依据：发现 N、M / 强度」，右侧多一行小字「翻转条件：…」（等宽标签 + 正文，同发现页证据行）。因多一行，B 海报方向下 4 条 + 2 行标题时 h2 降到 40px、行内 padding 14px（与主 skill §5b 容量规则同口径）。
- **模型输出页** = 图页或 E3 结论页，页脚来源行写「输入：[n][m]；模型：…」，输入清单进讲稿。

## 干跑验证结果

用下面两份页面计划把方向 2、4 的典型内容逐页套到现有页型与规则上，结论：

1. 「换标签集 + 放开建议」两处改动覆盖了方向 2 的全部页面和方向 4 的第 ①–⑤、⑦–⑧ 章。
2. 两处不够用、已在本文补上：方向 4 第 ⑥ 章的预算预测需要「模型输出必须列输入」（R2），否则一页预测图没有任何可核对的来源；方向 2 第 ⑦ 章进入模式对比是定性矩阵，会被主 skill 的表格规则误判成「改图页」（R8）。
3. 不需要新增版式：建议页用发现页版式加一行即可；风险预警用主 skill 已有的风险矩阵图页。
4. 工具链零改动：`deckfig.py`、`figaudit_slides.py`、`fit_text.js`、`render_deck.js` 对内容类型不敏感。
5. 未验证的部分：以上是规格层面的干跑，没有用真实公司跑一遍取证；真实跑一次最可能暴露的是 R5 的来源可达性（目标国监管站点、交易所公告是否被网络策略拦截）。

## 待办（扩到其余方向时再做）
