# 方法页

- 证据七类：实际值 / 自采数据 / 估计 / 预测 / 模型输出 / 厂商自述 / 推断；强度三级：强（多类独立证据一致）/ 中 / 弱。本报告无自采数据。
- 口径：茅台利润表「营业总收入」= 营业收入 + 财务公司利息收入；年报「经营目标」用营业总收入，季报首页用营业收入。两者在本报告分列，不互换。
- 比率（毛利率除外）由三表原文直接计算，标「实际值（计算）」并写算式；年报内已给出的毛利率、ROE 直接引用。
- 来源可达性：取证期间上交所静态站有机器人拦截，年报与季报原文取自公司官网投资者关系页与巨潮资讯网；两者均为法定披露渠道的同一文件。2021 年营业总收入未开到原文，只有检索摘要，标「中」。
- 「模型输出」页（第 6 章）每个输入在页脚列出来源编号，强度取最弱输入。
- 「厂商自述」：年报经营计划、业绩说明会、董事长股东大会发言；三表数字不归此类。
- 本报告不编排名，不做 STP/4P；建议只在第 8 章建议页出现，每条带依据的发现编号与翻转条件。
